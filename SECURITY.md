# Security Policy

Please do not report exploitable vulnerabilities, credentials, or private data
in public issues or pull requests.

Use GitHub's private vulnerability reporting for this repository if it is
available. If it is not enabled, contact the repository maintainer privately
through [GitHub](https://github.com/DhawalShankar) to arrange a secure report.
Include the affected component, impact, and steps to reproduce, but do not
include real credentials or production data.

Security fixes should avoid exposing vulnerability details until a fix or
mitigation is available.
